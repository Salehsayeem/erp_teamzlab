## RED evidence (watched failing, deterministic forms)

- Stale-snapshot form (MoneyHardeningTests convention) for the single-row flips: count close —
  stale scope committed (returned Closed count); impairment — stale approval returned data with
  AccumulatedDepreciation 600.
- Two-caller barrier form (ProcurementDeepTests FIX-4 convention) for the aggregate guards: hold
  the row the writers UPDATE at SaveChanges in a separate transaction, fire both, release —
  depreciation observed `[OK, OK]` (both committed, same period); receives observed
  `[InternalServerError, Created]` (both passed the guard, loser crashed on the shared stock row).
  The barrier makes exposure deterministic, not clock-luck.

## Honest concerns

1. **`SalesOrderService.Ship` stock race remains open** (out of the 4-fix scope cap): the
   availability check (`QtyOf(sku)` vs qty, negative-stock block) is an aggregate read on
   `stock_levels` with no lock — two concurrent ships of the last units can both pass and post
   COGS on phantom stock (negative on-hand). Same shape as the receipt race; fix would be a
   `stock_levels`-row FOR UPDATE + under-lock re-check. Recommend the next money-path wave.
2. **Dev-DB migration apply needs a probe**: `AddDepreciationPeriodUniqueIndex` will fail to
   apply on any database that already holds two depreciation runs for one (tenant, entity,
   period). Test DBs are fresh each run (green); the persistent dev DB (5433) should be probed
   for duplicate periods before the dev-sayeem regression applies it.
3. **Token choice for asset events is `JournalId`, not a status column** — asset_events has no
   status field; the flip column is the journal stamp. Insert-only writers (depreciate/transfer
   events stamp at creation) are unaffected; only the three approval UPDATEs are guarded.
4. The receive race's RED loser surfaced as a 500 (stock-row collision), not a double-post —
   the shared `stock_levels` row accidentally capped the damage. The GREEN refusal is the
   designed behavior; do not rely on the accidental cap.
